does not rebuild FlashInfer. The sampling module is compiled during first
preparation against the box's SDK and TVM-FFI, then reused from the JIT cache.

installation is needed.

The ALA wheel is specifically ppu10 / SDK2.2.1-184ee6. Do not use this binary for
ppu15; build a complete matching serving wheel for that target. Native ALA
resources are byte-identical to the previously tested 0.2.0 wheel. Only the
Python fake binding is changed; the manifest records both source revisions.
Do not edit installed Python files in place: that invalidates the package seal.

FlashInfer is based on t-head/flashinfer-for-sail ppu/0.6.18 e502dcf, with the
Flare prepared sampling interfaces from local-inference-lab/flashinfer 560fef1.
It is a PPU source-containing wheel. The host-linked sampling.so is deliberately
not shipped because the box must use its own SDK and TVM-FFI. Its distinct
version creates a separate JIT cache; do not force reuse of older sampling AOT
artifacts, whose FFI lacks row_independent_rng. Operator patch commits have not
been pushed upstream by this framework change.
