The local source checkout is /root/llama.cpp-ppu-backend.

For element i in a block, q = (qs[i/4] >> (2*(i%4))) & 3; value = (q-1)*d.
The four codes are -1, 0, +1, +2 times the stored FP16 scale. Preserve signed
scales and the original scale/code bits. Q2_K (ID10, 256/84) is a different
encoding. Do not alias ID42 to Q2_K or silently requantize it to Q8/Q4.

Implemented interfaces
----------------------
The earlier gap at e7743104 is closed. ID42 now has an exact raw reader and
canonical layout 6, mapping 0x5132304b50000001: low code words plus unchanged
FP16 scale units, with no high plane. Use native16 Library without packed_route;
the separate packed-route selector remains specific to Q5_1. Small M<=8 reads
compressed weights directly; larger M uses bounded expansion and grouped TC.
Serving gather_rows also admits ID42 for preparation-time dense expansion.
The complete wheel exists locally; registry publication and PPU validation are
separate steps. No performance result follows from host checks.
